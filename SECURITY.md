# Security Policy

This is the default security policy for repositories in the Selfkin organisation that do not have their own.

Please report security or privacy problems privately through **GitHub private vulnerability reporting** on the affected repository (Security tab, then **Report a vulnerability**). Do not open public issues or pull requests for unfixed problems, and do not report by email.

- Flaws in the specifications: [selfkin/standards](https://github.com/selfkin/standards/security/advisories/new), see its [SECURITY.md](https://github.com/selfkin/standards/blob/main/SECURITY.md).
- Bugs in the reference code: [selfkin/reference](https://github.com/selfkin/reference/security/advisories/new).

Response times and coordinated disclosure terms are described in the [standards SECURITY.md](https://github.com/selfkin/standards/blob/main/SECURITY.md).
