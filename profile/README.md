# SI Edge

**Draft open standards for personal SI runtimes on user-owned edge devices.** A personal SI is an AI agent runtime that runs on hardware you own and becomes your interface to devices, apps, services, and other agents, with your data, credentials, and memory staying with you by default. Model-agnostic and vendor-neutral.

> **Status: Draft, not for implementation. No certification program exists.** The project name is provisional.

- **Standards repository:** [SI-Edge/standards](https://github.com/SI-Edge/standards) (runtime SIE-RT, communication SIE-COM, provider profiles SIE-PRV, JSON Schemas, validator)
- **Web page:** https://si-edge.github.io/standards/
- **Discuss:** [GitHub Discussions](https://github.com/SI-Edge/standards/discussions)
- **Contribute:** read [CONTRIBUTING.md](https://github.com/SI-Edge/standards/blob/main/CONTRIBUTING.md), pick an [open question](https://github.com/SI-Edge/standards/issues?q=is%3Aissue+is%3Aopen+label%3Aopen-question) or a [good first issue](https://github.com/SI-Edge/standards/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22). Commits need a DCO sign-off.
- **Security or privacy flaw in a spec:** report it privately via [GitHub private vulnerability reporting](https://github.com/SI-Edge/standards/security/advisories/new), see [SECURITY.md](https://github.com/SI-Edge/standards/blob/main/SECURITY.md).
